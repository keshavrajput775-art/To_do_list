# CLI To-Do List in Python

A lightweight command-line to-do list application written in Python. Tasks are automatically saved to a local JSON file (`tasks.json`) so your list persists between sessions.

## Features

- **View Tasks:** Displays all tasks along with their completion status (`[✓]` or `[ ]`).
- **Add Tasks:** Quickly add new tasks to your list.
- **Toggle Status:** Mark tasks as completed or move them back to pending.
- **Delete Tasks:** Remove tasks you no longer need.
- **Persistent Storage:** Automatically reads from and writes to `tasks.json`.

## Prerequisites

- Python 3.6 or higher (uses only built-in modules: `json` and `os`).
